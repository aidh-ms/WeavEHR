# MIMIC-IV demo as ricu reads it

The MIMIC-IV demo as ricu 0.6.3, with YAIB's `ricu-extensions`, reads it; see
[`mimic-iv-ricu`](../mimic-iv-ricu/).

`2.2/` extends `mimic-iv-ricu` 2.2. A version extends one version only, so
`tables/procedureevents.yml` restates the demo's file layout from
[`mimic-iv-demo`](../mimic-iv-demo/) 2.2 (keep both identical). There are no
demo-specific mappings.
